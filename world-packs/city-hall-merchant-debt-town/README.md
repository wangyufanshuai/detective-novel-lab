# City Hall Merchant Debt Town

Original v2.8 world package for Detective Novel Lab.

This package models a detective-town ecology around city permits, merchant debt, clerk records, family obligation and press pressure. It is table-driven through `agent-pack.json` and `ecosystem-catalog.json`; it does not include runtime checkpoints, hidden culprit truth, API keys, absolute paths or copied external content.

Use it from Review Mode through World Packages, or from the command line:

```powershell
npm run package:validate -- --package=city-hall-merchant-debt-town
npm run package:export -- --package=city-hall-merchant-debt-town
```
