# 第三章 多出来的钥匙

我走下楼梯时，大厅里的壁炉还在燃烧，橘红色的火光在墙面上跳动着。但我没有走向壁炉，而是径直走向了东侧墙壁上的那个红木钥匙柜。

柜门仍然敞开着，和我晚饭后离开时一样。铜牌上的“听雪馆”三个字在火光中泛着暗沉的光泽。我站在柜门前，借着壁炉的光亮和走廊里传来的灯光，仔细端详着柜子内部的构造。

两排铜钩，每排六个。第一排从左至右，依次挂着“正门”、“后门”、“客卧①”、“客卧②”、“客卧③”、“客卧④”。第二排则依次是“储藏室”、“酒窖”、“档案室”、“保险库”、“顶楼阁楼”——以及最右侧，那本该空着的第十二号钩。

但此刻，第十二号铜钩上，挂着一把钥匙。

我的手在触碰到那把钥匙之前停顿了片刻。不是因为恐惧，而是因为一种逻辑上的错位感——就像看到一道数学题里出现了不该出现的数字，一个方程中多了一个未知数。

我取出钥匙，将它拿到壁炉边的灯光下仔细端详。

这是一把老式的铜钥匙，大约六厘米长，尾部有一个简单的圆环，齿纹清晰可见，锈迹斑斑——和刚才许文谦从柜中取走的那把钥匙一模一样。我用自己的手指在钥匙的表面滑动——纹路清晰，但触感有些过于光滑，像是被仔细清理过，或者——我翻转钥匙，凑近壁炉的火光仔细看——像是被人刻意打磨过。

但这把钥匙和许文谦取走的那把，在视觉上几乎别无二致。

“顾先生？”贺微澜的声音从楼梯口传来，她紧跟着我走了下来，后面还跟着贺明修和贺叔平。

我将钥匙举到火光中：“你们看。”

三个人同时走近，目光落在我手中的钥匙上。贺微澜最先反应过来，她的瞳孔微微放大：“这——这不是许律师拿走的那把钥匙吗？他明明——”

“不，”贺叔平的声音低沉，“他拿走的那把钥匙，门内侧还插着呢。”

“所以这是第二把书房钥匙？”贺明修的声音里带着难以置信的意味，“但这不可能啊——许文谦说过，只有一把钥匙！”

我没有立刻回答，而是再次看向钥匙柜的内部。第十二号铜钩上确实挂着钥匙——就是我现在手中这把。但我的目光没有停留在钩子上，而是落在了钩子周围的柜壁上。

柜子内部的木板是深色的，应该是胡桃木或者桃花心木，经过了多年的擦拭和氧化，表面泛着温润的光泽。但在第十二号钩的正上方，木板上有一处隐约的反光——像是被什么东西长期摩擦过留下的印记。

我伸出手指，轻轻触碰那个印记。表面有一层薄薄的灰尘，但印记本身是光滑的，像是被反复摩擦过。我顺着印记的轮廓划了一圈——它是一个规则的圆形，直径大约比我手上的钥匙环大了一圈。

“这是什么？”贺微澜也注意到了我的动作。我侧过身子，给她让出空间，让她能够看清楚。

“挂痕。”我说，“长期悬挂钥匙形成的金属摩擦痕迹。每一种钥匙的挂痕，理论上应该和它的钥匙环大小吻合。”

我拿起手中的钥匙，将钥匙环贴近那处痕迹：“但这个痕迹——比这把钥匙的钥匙环要大。”

“你的意思是——”

“这个痕迹，原本挂着另一把钥匙。”我放下手中的钥匙，再次看向柜子内部。我的目光在每一个铜钩上停留片刻——每个钩子上方，都有相似的挂痕。这些痕迹的大小和形状，都与目前挂在钩子上的钥匙环大小一致。只有第十二号钩的痕迹，明显偏大。

“但这不能说明什么，”贺叔平的声音从旁边传来，“也许这把钥匙只是被拿下来过一段时间，然后又挂回去了。”

“但这个痕迹——”我将手指再次放在那处痕迹上，然后比划着周围的木板表面，“周围木板上的灰尘是完整的。如果这把钥匙是最近刚被挂回去的，那么它的钥匙环应该会破坏灰尘的分布。但你们看——挂痕内部的灰尘和周围的灰尘，在厚度和分布上是一致的。”

“所以这把钥匙挂在这里已经有一段时间了？”贺微澜说。

“或者，”我走向窗边，将钥匙放在窗台的雪光下，“这把钥匙不是被挂回去的，而是它从来就没有被取下来过。”

“不可能！”贺明修提高了声音，“我们都看到了——许文谦明明从这里取走了第十二号钥匙！”

“他确实取走了。”我转过身，手中的钥匙在雪光的映照下泛着暗淡的光泽，“但他取走的那一把——和这一把，真的是同一把吗？”

大厅里沉默了几秒。壁炉里的火焰发出轻微的噼啪声，有一根木柴在烧断，火花跳到了地上。

“你的意思是，柜子里有两把书房钥匙？”贺微澜的声音很低，但她的眼神很专注，“一把被许律师取走了，另一把还挂在柜子里。”

“这说不通，”贺叔平摇了摇头，“如果柜子里原本就有两把书房钥匙，那为什么许文谦要强调只有一个？他应该知道——”

“他可能不知道。”我打断了他，“或者——他刚刚知道。”

我没有继续说下去，而是走到壁炉边，将手中的钥匙举在火光中仔细端详。钥匙的材质是铜，表面有些许发绿，但整体保存得相当完好。尾部的圆环上，刻着一个极小的数字——我眯起眼睛，借着火光仔细辨认：

“12”。

这是第十二号钥匙。

我翻转钥匙，看向钥匙的齿纹——那些齿纹的形状是标准的铜钥匙齿纹，阶梯状的缺口深浅不一，排列成特定的顺序。我抬头看向身边的贺叔平：“贺先生，您收藏古董和锁具？”

贺叔平点了点头：“有些年头了。”

“能不能请您看一下——这把钥匙的文字和齿纹，是否属于听雪馆原有的钥匙系统？”

贺叔平接过钥匙，从口袋里掏出一只折叠的放大镜，这是他随身携带的工具之一——收藏家的习惯。他仔细端详着钥匙的齿纹和文字，眉头微微皱起：“齿纹是标准的老式铜钥匙系统，听雪馆的旧锁都用这种系统。但——”

“但什么？”

“这个12的刻字，”贺叔平指着钥匙尾部的数字，“笔画的深浅不太一致。你看，”他将放大镜递给我，“‘2’字的笔画很深，‘1’字稍浅，而且两个数字的间距比正常的编号钥匙要大一些。”

我接过放大镜，仔细观察。果然如他所说，“12”两个数字的雕刻痕迹，在深浅和间距上，与其他编号钥匙不太一致。我拿出钥匙柜里的另一把钥匙——第九号“档案室”——上面的“9”字笔画均匀流畅，显然是同一批刻上去的。而第十二号钥匙上的“12”，则像是后来补刻上去的。

“这可能说明，这把钥匙的编号是后来才加上去的。”我说。

“后来？谁有理由这么做？”贺微澜问。

我没有回答这个问题，而是转向外面的方向：“还有一个问题——窗外。”

我走到大厅入口处的那扇窗户前，推开窗扇。寒风再次涌入，我探出头，看向二楼的窗户——书房的东窗。从这个角度看去，书房的窗户与一楼的地面之间，是笔直的石墙，墙面覆盖着一层完整的积雪，没有任何攀爬或踩踏的痕迹。书房的窗台上，也是一片干净的白色，没有任何脚印或者物品移动的痕迹。

我关上窗户，转身面对大厅里的三个人：“书房的窗外，雪是完整的。没有人从窗进入，也没有人从窗离开。”

“所以那个密室，是真正的密室？”贺明修的声音里带着一种不安。

“不，”我摇了摇头，“密室的存在，本身就是一种逻辑矛盾。如果没有人能从窗外进出，而门内侧锁着钥匙，那么凶手要么是许文谦自己，要么——”

“要么什么？”

“要么，”我走到壁炉边，将手中的钥匙放在壁炉架上的铜质托盘里，“这个密室，存在一个我们还没看到的漏洞。”

我注意到，我说出这句话时，贺叔平的目光在壁炉的火焰上停留了片刻——只是一瞬，然后又恢复了正常的注视。

“但是，顾先生，”贺微澜推了推眼镜，“就算柜子里出现了第二把钥匙，我们目前能证明的是——钥匙柜里又多了一把明明不应该存在的书房钥匙。这意味着——”

“意味着，”我替她把话说完，“要么柜子里原本就有两把书房钥匙，那第十二号钥匙就从来不是唯一的；要么，有人在我面前，制造出了一把新的钥匙。”

“如果是第二种情况，”贺明修的声音有些紧张，“那这第十三把钥匙——它代表了什么？”

我抬起头，看到他的目光正落在我放在壁炉架上的那把钥匙上。

“第十三把钥匙。”我重复了一遍这个词，然后看向楼梯口的方向，“刚才许文谦的便签上，也写了‘十三’。”

大厅里的空气似乎凝固了一秒。

“会不会，”贺微澜的声音打破了寂静，“他留的‘十三’，指的就是这把多出来的钥匙？”

我没有立刻回答，而是走到壁炉边，再次拿起那把钥匙，仔细端详着它的齿纹。

“要验证这个猜想，我们需要做两件事。”我说。

“什么事？”

“第一，”我竖起一根手指，“确认这把钥匙和门内侧插着的那把钥匙，在齿纹上是否完全一致。”

“第二，”我顿了顿，“确认这把钥匙——是否能够打开书房的门。”

贺明修和贺微澜交换了一个眼神。

“如果两把钥匙都能打开书房门，”贺微澜缓缓说道，“那就证明有人确实复制了钥匙。”

“如果打不开呢？”贺明修问。

“如果打不开，”我看向楼梯的方向，“那就意味着，这把多出来的钥匙——”我的目光在火光中闪烁了一下，“——是一个陷阱。”

——在真相尚未明朗之前，所有的不合逻辑都只是线索的碎片。而第十三把钥匙的存在，就像一道裂缝，正在撕开着看似密闭的密室结构。

窗外的雪还在下，像是永远不会停止。

在这栋被大雪封死的旧宅里，第十三把钥匙的谜题，正在等待着解答。
