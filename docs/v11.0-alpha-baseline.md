# v11.0-alpha Stabilization Baseline

## 状态

v11.0-alpha 是可提交、可构建、可验证、可继续扩展的正式 Alpha 基线。它冻结当前 12 个 Campaign、24 条 authored route、72 个 authored treatment，并继续复用既有 Persistent Town、Route Certificate、Truth Ledger、判定与 NPC legal-action authority。

本版本不新增 world loop、endpoint、schema、proof card 或第二套 case engine。Campaign / route 只影响安全的未来 case preference、公开语境、WorldPackage 绑定、Lead focus 和 finale 文案；抽取后的 truth、evidence coverage、Route Certificate、judgement 与 NPC legal actions 仍由同一套本地规则决定。

## 可复现运行入口

### Pull Request 快速层

```powershell
npm.cmd run test:twelve-campaign-smoke -- --json
```

它验证每个 Campaign 的基线 route（12 × 3 = 36 case），并保持固定 seed。两条在默认 seed 下可能延迟真实 crime trigger 的新 route 使用经过复核的稳定后缀：`floodgate-covenant/counter-route -> a`、`midnight-chorus/counter-route -> a`。这只解决有限窗口内的可达性，不改变候选合法性。

### Nightly / RC 完整层

```powershell
npm.cmd run test:seventy-two-case-campaign -- --json
npm.cmd run quality:rc -- --json
```

完整层覆盖 12 × 2 × 3 = 72 case。`quality:rc` 已升级为 `v11.0-alpha` 报告版本，并保留 v10 distribution compatibility、protected public hash、动态端口、临时 SQLite 和 cleanup 约束。

### 资产与包验证

```powershell
npm.cmd run test:v11-world-packages -- --json
npm.cmd run test:noir-presentation -- --json
```

## 后续开发路线

### Alpha.1：可观测性与失败归因

1. 将 72-case 结果保存为本地 ignored evidence manifest（仅保留 route、case ordinal、耗时、pass/fail 与安全摘要）。
2. 为 candidate queue 输出稳定的拒绝原因聚合，区分 trigger、means、route integrity 与 evidence coverage。
3. 将 Browser matrix 的 console、network、overflow、focus 结果纳入同一份 Alpha report。

### Alpha.2：表现层完成，不扩 authority

1. 按 license register 逐批补齐 12 Campaign 的 cover/map/chapter/finale/portrait/evidence，单文件先过尺寸、格式、hash、许可和无孤儿门禁。
2. 只在真实音频文件到位后将对应 track 从 planned 改为 ready；保持 Opus→MP3 fallback 与 Low Sensory 语义。
3. 完成 Campaign Front Door 的中英文文案审校、键盘 focus matrix 和 reduced-motion 复核。

### Beta 前：质量与扩展协议

1. 在不增加 API/schema 的前提下，建立 WorldPackage authoring template 与 package compatibility policy。
2. 以 24-seed fairness、72-case nightly、全视口浏览器矩阵和 protected-public hash 作为 Beta promotion prerequisites。
3. 只有当新增 Campaign 能提供完整 WorldPackage、三章 Route Certificate、双路线对比、中文安全投影和可复现 playthrough 时，才允许进入注册表。

## 明确未宣称

本基线不是 v11.3 complete，也不是 human comprehension / art-direction approval。未执行 5000/10000-tick gate、protected public artifact refresh、push、tag、release 或 deploy；未就绪的图片和音频保持 planned 状态。
