# 第三宗《撕下的那一页》交付说明

本文件含谜底，供内容审阅及 Claude 后端协作使用，不进入玩家投影。

## 内容与接入

- 案件：`missing-farewell-page`，版本 `riverbend-missing-farewell-page.v1`。
- 前置：《借来的凿子》结案；领取地点：河湾车站或警务所。
- 历史时间：第 1 天 05:00—05:59；实际取页窗口为 05:16—05:26。
- 四名嫌疑人、十二位居民证词、八份物证、五处搜查地点、两处必需的当面核对、三段结局。
- 数据位于 `packages/engine/src/cases/missing-farewell-page.ts`，仅在 `RIVERBEND_CASES` 追加注册。

## 谜底与公平性审阅

顾远山取走共同保管的离镇留言册第十七页，藏进自己的 G04 作废时刻册。他想保护旧旅客的去向，也想遮住自己没有转交保密请求的疏忽。保护隐私不能代替获得其他保管人的同意，结局由档案室保存原件、征求公开授权，并登记修复与保管责任。

推理依据全部出现在玩家可取得的物证正文中：

1. 物证 1：程渡与顾远山的两次签名和站台电波钟，把缺页限制在 05:16—05:26。
2. 物证 2、3：夹背护条与 G04 第四十八页缺口相合；藏在同册中的原页与展示夹纸茬、骑缝线相合。结合交接清单与其他人的行踪，排除仅凭旧书归属指认的跳步。
3. 物证 4：保密请求签收、空白转交栏及中午截稿通知提供动机。周砚代带至邮局待寄栏的过程写入历史，避免物证无故出现在别处。
4. 物证 5：白露 05:18 已到咖啡馆，最晚 05:13 离站；05:16 书页仍完整，且她无法在十分钟窗口里往返并取页。
5. 物证 6：沈映 05:12—05:32 与林阿梨连续核号，预约不等于到场。
6. 物证 7：周砚 05:16—05:26 与陆行舟连续誊信。代写私信解释隐瞒，也提供排除依据。
7. 物证 8：接触清单、在岗签名与无交接记录补齐保管机会。

误导包括沈映的第十七页拍摄预约、周砚对私人停留的否认，以及白露签过接触清单。必需核对为向周砚出示物证 7、向顾远山出示物证 3；其他物证不会自动改正这两处说法。

- 物证正文长度 83—97 字，十二份初始证词 74—85 字，三段结局 88—95 字。
- 参考页通过 `node scripts/check-cases.mjs --reference` 重新生成。

测试使用临时隔离数据库，不使用现有玩家存档。旧回归脚本原先断言“第二宗后无委托”，现已更新并继续验证第三宗结束后无新委托；不涉及后端业务实现修改。

本案不需要新增接口、地点、室内、跨天格式或引擎能力，沿用现有 `CasePack`。旧时刻册搜查沿用 `needsPresent`，要求顾远山在车站在场；原件封存，玩家取得共同清点记录。
