# 案件本查阅与草稿体验

本轮继续由 Codex 处理玩家界面，后端业务实现和判案规则未修改。正式站仍是用户已部署的版本；本轮没有发布、提交或推送。

## 改动

- 物证按已发现地点筛选，支持搜索标题、正文、时间或地点文字；显示匹配数量，提供空结果提示和清除按钮。
- 物证编号取公开物证 ID 的固定编号；筛选或尚未发现前面的物证时，不再从 01 重新编号。
- 证词按已询问人物筛选，可只看更正记录；出示物证的记录可以跳回对应物证。
- 动机、手法物证被勾选时，一并加入引用材料；移除引用材料时，同步移除其动机或手法分组引用。
- 提交前提示缺少哪些必填选择。填齐只表示表单完整，正确性仍由现有后端规则判定。
- 恢复草稿时校验人物、物证和数据类型，移除未知或未发现物证，去重并补齐分组引用。损坏草稿不能把对象写进 React 文本或勾选项。
- 结案状态条使用当前案件标题，移除固定的“第七分钟”。

源文件：`app/town-play/TownInvestigation.tsx`、`TownPlayClient.tsx`、`town-play.module.css`、`case-notebook.ts`。沿用 `docs/town-play-design-tokens.md` 的纸张、森林绿和黄铜令牌。
