# v11.1 Cinematic Deduction Gold Slice

## 状态与范围

`Midnight Chorus / Public Reckoning` 是 v11.1 唯一黄金切片。它验证表现层、推理手感与可观测性，其他 23 条 route 继续使用既有 Investigation surface。该切片不新增 case engine、判定路径、证据权威、NPC legal action 或持久化 schema。

自动化门禁已经覆盖双语、390 / 768 / 1440、键盘 focus、Low Sensory、reduced motion、network、console、overflow 与 authority isolation。人工理解度和 art-direction approval 仍为 `human-pending`；5000 / 10000 tick gate 已执行但当前为 `failed`，因此当前不得 tag、release 或 deploy。

## Motion Grammar

所有重要操作遵循同一条五段语法。动画负责解释状态变化，不负责制造规则或延迟权威结果。

| 阶段 | 玩家感知 | UI 责任 | 权威边界 |
|---|---|---|---|
| Focus | 我现在在处理什么 | 聚焦当前证据、证词、任务和唯一认证行动 | 只读取已有 public projection |
| Commit | 我刚刚决定了什么 | 对选择证据、质证或提交理论给出明确按压与连接反馈 | 调用既有认证 handler；不复制判定 |
| Resolve | 结果是否成立 | 显示已发现证据、矛盾、拒绝或接受状态 | 使用既有 Route Certificate 与 judgement 结果 |
| World Reaction | 城镇如何回应 | 展示安全、低剧透的 standing / recovery / finale 反馈 | 只允许既有、可审计的未来世界后果 |
| New Objective | 下一步是什么 | 把唯一认证行动和下一目标重新置于视觉优先级 | 不创建第二任务状态机 |

标准动效必须短、单次、可中断；不得用循环动效表达等待。`prefers-reduced-motion` 与 Low Sensory 都将动画和过渡压缩到不超过 20ms，同时保留 Focus、Resolve、World Reaction 和 New Objective 的文字与结构信息。

## Deduction Loop

黄金切片把既有七步认证路线压缩为一个可读的推理回路：

1. Evidence Table 选择已发现证据，并把证据加入 Theory Chain。
2. Contradiction Loop 选择证人和证据，通过原 Question / Challenge handler 检验陈述。
3. Theory Chain 组合嫌疑人、动机、方法与已选证据。
4. Certified Action 始终只有一个，继续调用当前既有 handler。
5. 结果进入 Resolve；错误理论进入 Theory Pressure，正确理论进入安全的 finale / next objective。

Evidence Table、Contradiction Loop 和 Theory Chain 是同一认证调查的三个视图，不是三个独立规则系统。任何表现层派生都不得改写 truth、evidence membership / coverage、candidate membership / ordering、Route Certificate、judgement 或 NPC legal actions。

## Theory Pressure

Theory Pressure 只在 `midnight-chorus / baseline / rejected-theory` 生效：

- 第一次错误理论立即、幂等地使 `Press Network / media` standing 降低 3。
- 重复读取、重复投影或重复同一失败不能再次扣减。
- 玩家必须显式启动恢复；恢复进入 `scheduled`。
- 下一个合法五 tick cadence 完成恢复并恢复 standing。
- 恢复只改变未来世界的可见信任状态，不改写当前 case 的任何证明或判定输入。
- 其他 Campaign / route 继续使用原有即时 certified-route review。

## 可访问性与理解度

- 所有关键控件有效点击目标至少 44px。
- 关键控件保留明确 `:focus-visible`，关闭 Front Door 后 focus 返回触发器。
- 中英文必须表达同一任务、行动、边界和结果，不允许中文只保留装饰标题。
- 窄屏不得产生页面或 deduction board 横向溢出。
- Low Sensory 是独立、可聚焦、可读出 pressed 状态的按钮，不得隐藏功能。

人工理解度使用 [campaign-comprehension-review.md](templates/campaign-comprehension-review.md)，art direction 使用 [art-direction-approval.md](templates/art-direction-approval.md)。在两项都签署前，Alpha report 必须保持 `human-pending`。

## 外部标杆与体验预算

黄金切片采用四个可追溯标杆，但只吸收适用于当前认证推理架构的原则：

| 标杆 | 采用原则 | 本项目验收预算 |
|---|---|---|
| [Overboard! 设计复盘](https://www.gamedeveloper.com/design/how-get-away-murder-overboard) | 先建立玩家可操纵的知识状态和 finale spine，再用自动 playthrough 找断路 | 每个核心动作必须改变认知、世界状态或风险；自动 72-case 不能替代真人理解度 gate |
| [web.dev RAIL](https://web.dev/articles/rail) | 即时操作应在玩家感知为“直接”的时间内反馈，动画帧不得挤占主线程 | 黄金切片关键本地反馈 `<150ms`，目标 `<100ms`；动画帧主线程工作目标 `≤10ms` |
| [W3C Animation from Interactions](https://www.w3.org/WAI/WCAG21/Understanding/animation-from-interactions) | 非必要的交互动效必须能被关闭且不丢信息 | `prefers-reduced-motion` 与 Low Sensory 下过渡/动画 `≤20ms`，因果状态全部保留为结构与文字 |
| [Xbox Accessibility Guideline 112](https://learn.microsoft.com/en-us/gaming/accessibility/Xbox-accessibility-guidelines/112) | 焦点顺序、导航和返回位置必须一致且可预测 | Front Door 键盘 5/5、关闭后 focus 恢复；三档 viewport 的原生 tab 顺序不漂移 |

这些预算是 ceiling，不是鼓励把每次动作拖到上限。动画只有在解释定位、因果、承诺或后果时才允许存在。

# Evidence focus spatial transfer (2026-09-06)

The Gold Slice now connects an already-discovered evidence card to the focused evidence panel with a 320 ms measured transfer. The existing selection setter runs immediately; the transfer neither dispatches a request nor owns evidence, theory, or judgement state.

The transfer uses a disposable copy of the visible card, with IDs, data locators and ARIA/live-region attributes stripped. It is inert, pointer-transparent and hidden from accessibility. The real card and destination remain the accessible source of information. Geometry is read from the source at selection and from the destination on the following frame; invalid or offscreen destinations skip animation without scrolling or blocking selection.

A new selection cancels the old transfer. Scroll, resize, component cleanup, Low Sensory and a system reduced-motion change cancel pending/active motion. A stale completion cannot remove a newer transfer. Completed/cancelled copies are removed.

`scripts/run-cinematic-spatial-transfer-tests.mjs` tests geometry and controller lifecycle with a mocked DOM. It is included in the normal workspace test. This is the first evidence-card-to-focus segment only: rendered trajectory, map/person/theory continuity and the complete five-phase action sequence still require implementation/verification. Do not use these unit tests as art-direction approval.
