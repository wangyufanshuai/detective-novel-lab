# 第七轮：约定结果的个人认知与当面核对

2026-11-03。继续 Agent 内核优先、轻量 2D 界面路线。把世界中的约定结果、居民亲历的事情和后来听到的说法分开保存。真实模型仍未启用。

## 新的闭环

同一项约定可以产生不同的个人记录：

- 接受时：双方知道自己答应了什么，来源是各自保存的回复事件记忆。
- 实际完成时：共同交谈的参与者才记为亲历履约。
- 未开场时：咖啡馆现场的人记住约定没有开始，以及当时是否见到了对方；缺席者不会获得咖啡馆的现场记忆。
- 约定时间过去后：仍记得约定、但没有自己的完成记录的居民，只能形成“我没有完成这次见面，不知道对方当时的情况”的私人认知。
- 以后真正碰面并完成交谈时：双方可以核对旧约定。没赶上的人承认自己没能按时来，听者记录为未核实的转述。旧约定仍保持原来的结果。

当前说明是编写好的自我承认，不会凭空补出“被谁阻拦”“因为案件耽误”等具体理由，也没有实现开放式对话、谎言生成或独立调查核实。

## 认知会影响实际选择

居民对曾经亲历“当时没见到对方”的熟人，会暂时多一点谨慎。这只影响本人的择伴排序和接受邀请时的有效评价，不向全镇传播负面声誉，也不判定对方故意欺骗。

每次未解释经历的谨慎量为 0.3，听到当面承认后降为 0.1，总量上限 0.9。这些是明确编写的试验规则，不是经过心理学或真人游玩校准的参数。原有真实交谈带来的社交效果仍照常运行。

受控对照保持相同需求、相同信任和相同合法候选，仅移除本人那条衍生认知记录后，实际选择的交谈对象会改变；原始事件和记忆仍然保留。这个检查比较实际行动，而不只是比较存档摘要是否不同。

## 来源、隐私与提供者边界

每条个人记录必须对应本人拥有的事件记忆和原始事件，且事件参与者中有本人。世界中的约定状态或私有失败原因，不能直接设置本人的看法。

旧存档在下一次世界时钟边界，可从已有的个人来源记忆重建这层记录；读取手记不会写入认知。没有相关个人记忆时，不会因为全局约定表里有记录就补上知识。

当面说明保留说话者、事件来源和 `unverified` 标记，不替换先前的亲历记录。执行时会拒绝伪造来源、别人的经历、错误的约定归属以及把转述改成已证实的记录。

生活模型观察升级为 `resident-life-policy.v4`，至多附带本人的四项近期认知。它不包含他人的认知、全局失约原因或任意人物的实时状态。模型接口继续只能返回当前合法候选编号。

玩家界面仍只显示当前可见活动；居民真正核对旧约定时可显示“核对上次约定”。完整个人认知表和他人的说法来源不暴露到公开 API。本轮没有新增查看隐藏思想的玩家接口。

## 验证与范围

当前通过情况与源码摘要见 `review.json`。自然模拟中的记录数量见 [outcomes.zh-CN.md](./outcomes.zh-CN.md)。

- 七组认知检查覆盖：私人记忆、多个约定的正确归属、现场与缺席者的不同看法、实际择伴变化、当面说明仍未核实、拒绝伪造确定性、旧记忆重建、存档恢复和检查点重放。
- 目标模式五个种子各运行 72 小时，并完成中途恢复和独立重放。另有一个日程种子的三日回归。本轮没有重新做五组双模式质量对照。

- 浏览器覆盖自然产生的赴约活动、窄视口和私有认知隔离；本轮新增的当面说明闭环在受控引擎情境验证，不能冒称已在浏览器自然目击。窄视口不代表真实手机。
