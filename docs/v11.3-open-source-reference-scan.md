# v11.3 开源参考扫描

扫描日期：2026-10-03。通过 Exa 搜索开源仓库，再读取四个主仓库页面；这些项目用于提炼接口和门禁思路，不作为本项目的代码、性能或生产质量证明。引入任何代码前仍需逐仓库复核当前 commit、许可证、依赖和安全边界。

| 参考 | 可迁移的工程模式 | 在本项目中的落点 |
| --- | --- | --- |
| [HYPNIC CORE](https://github.com/DISHANTUS/HYPNIC-CORE)（仓库页标为 MIT） | 固定步长、单一 seeded RNG、输入日志重模拟、每 tick hash、版本化 `WorldBundle`/`SessionRecord`/`ObservationEvent` 合同；观察层只读，不改变模拟。 | `world-replay-compat.v1` 固定 engine/random source/tick/package identity；`agent-control.v1` 将 observe 与 commit 分开。随机源和 hash 仍以本仓库实现为准。 |
| [Vitric](https://github.com/BlackBearCC/vitric)（仓库页标为 MIT） | 无头 HTTP 控制面、结构化状态查询、精确 replay、snapshot/restore、lookahead、swarm playtest 和 delivery gate；把“可玩”拆成可计算的机械门槛。 | 继续把 replay executor、CAS commit、长跑公平性和浏览器 QA 做成可重放收据；艺术质量仍保留人工 gate。 |
| [Agent Control Plane](https://github.com/phoenix1803/Agent-Control-Plane)（仓库页标为 MIT） | 每个 agent step 有不可变 trace、输入/输出/tool call/state snapshot、无 live LLM 的 replay、行为断言和 trace diff。 | 下一步为 `agent-control.v1` 增加 step trace 与 source reference resolver，复用现有 `decisionTraces`、`interventions` 和 replay digest。 |
| [Pascal Editor](https://github.com/pascalorg/editor)（仓库页标为 MIT） | schema-first scene nodes、viewer/editor 分层、registry、dirty-node 增量系统、React Three Fiber/WebGPU、门窗 CSG 和参数化建筑编辑。 | 3D 房间采用数据驱动的 room layout/props/openings，渲染层不写世界真值；先通过 Function/Form/Runtime 门禁，再接入调查房间 UI。 |

## 取舍

- 只吸收“合同、重放、可观察性、门禁、数据驱动几何”这些可验证原则，不复制外部项目的未审计实现。
- 2D/无头测试先证明世界与 Agent 行为；3D 只是同一真值的派生视图，不能回写 tick、事件、案件来源或玩家证据。
- 外部项目的 stars、宣传语和搜索摘要不构成质量结论；本项目仍以本地测试、RC smoke、真实资产 provenance 和人工理解度验收为准。
