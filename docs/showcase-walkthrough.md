# Showcase Walkthrough

The default Showcase is designed to be understandable in one minute:

1. Start the app with `npm run dev -- -p 3000`.
2. Click **Create Detective Town**.
3. Join the case as a player.
4. Search the crime scene and related locations.
5. Interrogate an NPC with and without evidence.
6. Open **Developer / Agent API** and copy the integration example.
7. Submit an incorrect theory and verify it fails.
8. Discover the decisive evidence chain and submit the correct theory.

The Showcase target is 8 NPCs, 9 locations, 24 hours, one murder case, event-backed evidence, memory-scoped testimony, and a unique culprit.
