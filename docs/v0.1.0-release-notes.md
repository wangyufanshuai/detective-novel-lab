# Detective Town v0.1.0

Detective Town is a local-first mystery engine where cases emerge from simulated NPC lives, then become playable through event-backed evidence and local fair-play validation.

## Highlights

- Persistent Agent Town: NPCs observe, update memories, score actions, create events, and surface case candidates.
- Scenario Runner: deterministic baseline and counterfactual branch runs with pass/fail reports.
- World State Time Machine: tick snapshots, diffs, and rollback for runtime debugging.
- Living World Audit Studio: audit imported novel worlds and apply correction overlays without mutating source chapters.
- Agent API: stable `/api/v1/*` wrapper for external scripts and agents.
- SDK starter: zero-dependency Node client under `examples/sdk`.
- Static Demo readiness: Vercel Static Demo path requires no API key or writable database.

## Validation

The release workflow verifies:

```powershell
npm run test
npm run build
npm run benchmark:emergence
npm run test:scenario-api
npm run test:sdk-client
```

The full local release checklist also includes browser E2E, all Agent API smokes, and Docker smoke when Docker is available.

## Known Limits

- v0.1.0 does not include hosted Server Runtime infrastructure.
- The SDK is not published to npm yet.
- Static Demo does not call `/api/*`; Scenario Runner, Time Machine, and Agent API require Server Runtime.
- DeepSeek can improve dialogue prose, but local deterministic rules remain the authority for case validity.
