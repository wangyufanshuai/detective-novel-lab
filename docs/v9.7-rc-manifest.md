# v9.7 Release Candidate Manifest

## Identity

- Release line: `v9.7 Release Candidate Freeze`
- Source branch: `feat/v9.2-campaign-command-clarity`
- Frozen feature baseline: `ffb9b1a` (`v9.6`)
- Intended local freeze commit: `chore(release): freeze v9.7 release candidate`
- Product inventory: four Campaigns, eight authored routes, 24 treatments, eight distinct Finale families
- Runtime inventory: 125 API route files, one certified investigation authority, one Persistent Town runtime format

v9.7 adds no Campaign, case type, world loop, resource, endpoint, schema, event, tick, proof card, UI framework, public artifact, remote service, or background worker. The release changes validation ownership, QA isolation, release documentation, and release-blocking defects only.

## Canonical gate

Run from the repository root after dependencies are installed:

```powershell
npm.cmd run quality:rc -- --json
```

The command is fail-fast and read-only with respect to protected public artifacts. It reports every completed stage with status, duration, exit code, and output tails. Its coverage includes TypeScript, core model/authority tests, the 24-seed fairness sweep, all eight routes and 24 Campaign cases, content validation, production build, isolated Persistent Town API smoke, performance, repository/privacy checks, Static reader verification, and all Server/Static browser gates.

Every Server QA process receives a dynamic loopback port, mock AI provider, empty provider-key environment, and a unique temporary SQLite file under `data/`. The lifecycle helper kills the spawned process tree and removes the database, WAL, SHM, and journal files in `finally`, including startup failure and stage timeout paths.

## Frozen boundaries

- Static Runtime resolves before Server bootstrap and makes zero `/api/*` requests in both `en-US` and `zh-CN`.
- Static Runtime writes no Server launch pointer, Study record, bootstrap sentinel, or Persistent Town state.
- Server Runtime remains authoritative for persistence, Campaign progress, world consequences, and investigation sessions.
- Truth, Route Certificate, evidence coverage, judgement, candidate membership/order, and NPC legal action membership remain governed by the existing engine.
- `public/dataset-reader` and `public/review-catalog` are hash-checked before and after the gate and are never regenerated by `quality:rc`.
- Provider credentials may come only from environment configuration; the RC harness clears them and uses the mock provider.
