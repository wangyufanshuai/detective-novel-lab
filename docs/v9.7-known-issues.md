# v9.7 Known Issues

## Release-blocking status

There are no known P0 or P1 defects after the canonical RC gate. A new P0/P1 report reopens the freeze: do not tag, release, or deploy until the defect is reproduced, fixed without feature expansion, and the full gate passes again.

## Accepted P2 limitations

1. **Human comprehension is not validated.** The v6.2 recorder, privacy model, operations guard, and automated browser checks are ready, but the prescribed official participant matrix has not been completed. Automated completion, axe, keyboard, and timing evidence must not be described as `Human Gate passed`.
2. **Optional live dialogue is outside the deterministic RC authority.** The release gate uses the mock AI provider and clears provider keys. DeepSeek or another live dialogue provider may change surface prose or fail independently, but it cannot determine culprit, method, evidence, timeline, Route Certificate, or judgement.
3. **Protected public catalogs are intentionally historical snapshots.** This freeze validates their bytes and public safety without regenerating them. They are reviewer artifacts, not the authority for the four-Campaign Server Runtime.
4. **Visual validation is automated, not an art-direction sign-off.** Responsive geometry, focus, reduced motion, touch targets, and serious/critical axe findings are gated. Bespoke illustration, animation, audio, and long-session subjective pacing remain future product work.
5. **Local production startup requires a successful build.** Isolated browser/API QA uses `next start`; running an individual QA script against a missing or stale `.next` build should be preceded by `npm.cmd run build`. The canonical gate always builds before Server QA.

## Deferred maintenance

- Further component/CSS decomposition is allowed only in a later behavior-preserving maintenance release with the same authority and browser gates.
- Human Gate findings may justify layout, ordering, or copy changes in a later version; they are intentionally excluded from the v9.7 baseline.
- Additional Campaigns, world mechanics, case families, and public artifact refreshes require separately scoped releases.

None of these limitations changes current case fairness or creates a hidden client authority.
