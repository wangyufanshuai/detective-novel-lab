## 完成标准

1. 外层命令和推理台基于同一真实动作分发，Observe 不误触 Search；每次点击最多执行一次。
2. Join、Search、Question、Challenge、Submit、Reveal 明确返回成功、规则拒绝、阻止、取消或失败；公共结算按结果展示。
3. 玩家可用已发现证据分别证明动机和手法，笔记不按措辞评分；错误分组、未发现证据、单字和前缀否定无法接受。
4. 慢询问完成后合并最新会话，不覆盖期间新增证据、日志或判定；非法角色和未发现证据在模型调用前拦截。
5. 引擎反例、共享分发/React、实际 hook、SQLite/API、旧合同回归、TypeScript、生产构建、完整首案浏览器与适用 Campaign 回归通过，并保存同版本证据。

## 边界

这是工程闭环，不代表真人首次理解度、商业品质或美术批准。旧 `createShowcaseCase` 是非当前玩家入口的遗留 fixture，缺可见动机证据，结构化模式保持拒绝；旧标准陈述模式保留测试兼容。新的内容必须提供明确的动机与手法证据。没有扩大 Campaign、改变世界生成、公平性或长期世界再生规则。

## 回归入口

`npm run test:first-case-loop` 运行本轮六个专用套件及认证节奏回归。最终结果、浏览器记录和增量补丁见本轮输出目录中的验收报告。
